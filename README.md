<h1>Stock-trading-app</h1>

<p>A full-stack Zerodha-inspired trading platform built using MERN stack.</p>
<p>This project includes user authentication, dashboard integration, protected routes, and responsive UI design.</p>

<h2>Features used in this project</h2>
<ul>
  <li>User Signup and Login authentication</li>
  <li>JWT based Autherization</li>
  <li>Protected Dashboard Routes</li>
  <li>Password Hashing using bcrypt</li>
  <li>Responsive UI with React and Bootstrap</li>
  <li>MongoDB Database Integration</li>
  <li>Cookie-based Authentication</li>
  <li>MERN stack Architecture</li>
</ul>

<h3>Frontend</h3>
<ul>
  <li>React.js</li>
  <li>React Router DOM</li>
  <li>Axios</li>
  <li>Bootstrap</li>
</ul>

<h3>Backend</h3>
<ul>
  <li>Node.js</li>
  <li>Express.js</li>
  <li>MongoDB</li>
  <li>Mongoose</li>
  <li>JWT</li>
  <li>bcrypt.js</li>
  <li>cookie-parser</li>
</ul>
